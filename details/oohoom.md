## Overview

oohoom is an AI-powered platform designed to help users maximize the value of their Google Search Console (GSC) and GA4 data through an AI Assistant and Model Context Protocol (MCP) integration.

## Features

- AI Assistant for GSC and GA4 data analysis
- Model Context Protocol (MCP) integration
- SEO performance insights from search console data
