## Overview

Ryze is a free, open-source SEO MCP server and GEO skills package for Claude Code and AI agents. It connects to real Google Search Console, GA4, and ads data to provide keyword research, rank tracking, site audits, backlink analysis, and AI visibility tracking.

## Features

- SEO MCP server for Claude Code
- Keyword research
- Rank tracking
- Site audits
- Backlink analysis
- AI visibility tracking on GSC/GA4/ads data
- Installed via `claude mcp add ryze --transport http https://connector.get-ryze.ai/mcp`

## Pricing

Free and open source. Repository: https://github.com/ (MCP connector at connector.get-ryze.ai).

## Deployment

Cloud-hosted MCP server, self-hostable skills.
