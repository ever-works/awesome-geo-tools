## Overview

SE Visible aggregates prompt-level outputs into standardized performance scores. It runs prompts across multiple LLMs to extract mentions and sentiment, then converts them into visibility and sentiment scores per brand.

## Key Features

- Runs prompts across multiple LLMs to extract mentions and sentiment
- Converts data into visibility and sentiment scores per brand
- Prompt and topic breakdowns behind scores
- Multi-client reporting layer for agencies tracking multiple brands
- Consistent reporting across multiple brands

## Limitations

- Does not provide raw prompt-experimentation tools
- No attribution workflows
- Mostly a reporting interface built on top of collected LLM data

## Best For

Agencies that need standardized reporting across multiple brands.
