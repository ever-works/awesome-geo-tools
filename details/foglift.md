## Overview

Foglift is an AI-powered GEO readiness scanner that analyzes technical AI search factors including llms.txt, structured data, crawlability, and overall AI search visibility.

## Features

- AI-powered GEO readiness scanning
- llms.txt analysis
- Structured data analysis
- Crawlability analysis for AI crawlers
- AI search visibility assessment
- Free scan available
- API and MCP server access

## Pricing

Free scan available; paid platform with API and MCP server access.
