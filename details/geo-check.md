## Overview

geo-check is an open-source command-line interface tool that evaluates a website's AI crawler access and readability by analyzing robots.txt, sitemap, llms.txt, and sampled pages without using an LLM in the scoring path.

## Features

- Open-source CLI for AI crawler access scoring
- Analyzes robots.txt, sitemap, llms.txt, and sampled pages
- Deterministic scoring (no LLM in scoring path)
- AI crawlability and readability assessment
