## Overview

GeoReady, powered by the open-source GEO Optimizer engine, audits whether generative AI search engines (ChatGPT, Perplexity, Gemini, Google AI Overviews) cite a website. It is a CLI tool written in Python with MCP support.

## Features

- AI citation auditing for ChatGPT, Perplexity, Gemini, and Google AI Overviews
- CLI interface
- Python implementation
- MCP support
- Open-source engine behind GeoReady

## Pricing

Free and open source. Repository linked from https://geoready.dev/.

## Deployment

Self-hosted CLI.
